People and access

Accounts, roles and permission rules. These open in the Advanced view, the platform's configuration workspace.

  • Users Create an account, enable or disable one, and set which roles it holds.

Configuration and operations

How the platform is set up and how it runs. Apart from the first three, these open in the Advanced view.

  • Integrations The AI service, Doc AI, horizon scanning, email and single sign-on: what is connected, and what leaves the platform.
  • Imports Upload a file against an import profile, review each row, then commit or discard.
  • Attestation campaigns Open a campaign, generate its tasks, and see who has not answered.
  • Workflows The states and transitions each record type moves through.
  • What each status means Which statuses count as editable, in force or awaiting review. Add a row whenever you add a status.
  • Watched fields The changes that send a record back for review.
  • Notification channels Where the system's notices are sent.
  • Service levels The clocks that decide when something is late.
  • Retention classes How long each kind of record is kept.
    • {%- if is_system_manager %}
  • Scheduled jobs The background work, and when it last ran.
  • Error log What has failed, with the technical detail.
  • System settings Site-wide settings: time zone, formats, session policy.
    • {%- endif %}
  • Interface reference Every shared component, in both themes and at every text size.
